My AI — GenAI Chat Application

A ChatGPT-style conversational AI web application built with Flask and Hugging Face APIs.

Features

💬 Multiple conversations
🤖 AI chat using Llama 3.1
📝 Markdown responses
💻 Code blocks with copy
⏹ Stop generation
🔎 Search conversations
✏️ Rename conversations
🗑️ Delete / clear conversations
📄 Export conversations as TXT / JSON
🌙 Dark / Light mode
📱 Responsive UI
🔐 API key kept server-side

Tech Stack

Python
Flask
Hugging Face Inference API
HTML
CSS
JavaScript
LocalStorage
